# 装备速查悬浮窗

打本拍卖时用来快速看 / 改装等的置顶小面板。整体透明、无边框、始终在最前面，平时收成一个小图标。

## 下载（免安装）

到 [Releases](https://github.com/15164115976/gear-overlay/releases/latest) 下载 `gear-overlay-v1.0.0-win64.zip`（约 117MB），解压后双击 **装备速查.exe** 直接用，不用安装。
配置存在程序目录的 `data` 文件夹里，整个文件夹拷到别的电脑，配置也跟着走。

## 从源码运行

双击 `启动.bat`（第一次会自动装运行环境，之后就秒开）。

## 自己打包绿色版

```bash
npm install              # 装 electron
node build-release.js    # 产出 dist-portable/ 和 release/*.zip
```

## 界面

```
┌────────────────────┐
│ ▣  紫霞功  ＋      │   ← ▣ 点它收起（按住任意位置可拖动整块）
├──────────────┬─────┤
│ 帽子    1280 │ 护腕 740 │
│ 根骨    大附魔│ 小附魔 大附魔│
├──────────────┼─────┤
│ 上衣     740 │ 下装 740 │
│ 小附魔  大附魔│ 小附魔    │
└──────────────┴─────┘
```

每个小方块：

- **左上** 装备名  **右上** 装等（颜色随档位变：740 灰、965 淡紫、1110 金、1280 亮金）
- **左下** 小附魔  **右下** 大附魔（只有 帽子 / 上衣 / 腰带 / 护腕 / 鞋子 / 武器 有大附魔，其他格不显示）
- 灰色＝还没买，点一下变绿
- 窗口被拖到屏幕外、或换过显示器，下次打开会**自动拉回屏幕内**

## 操作

| 动作 | 效果 |
| --- | --- |
| 按住面板任意位置拖动 | 整块跟着鼠标走，松手放下 |
| 按住小图标拖动 | 同上（图标会脉动发光，表示手还按着） |
| 单击小图标 | 展开；面板的角就长在图标那个位置 |
| 点面板左上角的小图标 | 收起，图标回到同一个点，再点一下又展开 |
| 鼠标停在面板上滚滚轮 | 整体缩放（0.9× – 2.2×） |
| 拖右下角小三角 | 同上，手调缩放 |
| 点方块 | 原地弹出 740 / 965 / 1110 / 1280 四选一 |
| 点小/大附魔文字 | 灰 ↔ 绿 |
| 双击附魔文字 | 改文字（比如改成「根骨」「攻击」） |
| 双击角色页签 | 改角色名 |
| 右键角色页签 | 改名 / 删除 / 新增 |
| 右键面板 | 功能码 / 加角色 / 收起 / 退出 |
| `Ctrl + Alt + G`、`Esc` | 收起 / 展开 |

## 功能码（备份 / 换电脑 / 发给别人）

右键面板 → **功能码…**

- 弹层里会自动生成一串以 `GX1` 开头的码，默认全选，`Ctrl+C` 复制走（点「生成码」还会顺便复制到剪贴板）
- 导入：全选删掉旧内容，`Ctrl+V` 粘贴别人的码，点「导入」即可覆盖当前所有角色
- 一个角色约 350–450 字符，微信直接发就行

## 数据

存在 `%APPDATA%\gear-overlay\gear-overlay.json`，关掉再开自动恢复，位置 / 缩放 / 页码都会记住。删掉这个文件就恢复出厂状态。

## 说明

- 紫色方块的边框和底边亮条颜色取自你给的游戏截图（原图每格压着青色「拾取」角标，直接放大用会糊，所以按原色重画成矢量样式，缩放到多大都清晰）。
- 游戏如果是「独占全屏」，系统不允许任何窗口盖上去，请改成「窗口化全屏 / 无边框窗口」。
- 目录里的 `runtime` 文件夹是早期尝试复用系统 Electron 留下的硬链接副本（不额外占空间），被系统占用暂时删不掉，重启电脑后可以直接删，不影响运行。
